# 대학별 수학 논술 교정·합본 출고 계약

## 적용 범위

대학별 수학 문제·해설을 별도 최신순 합본으로 제공하는 작업에 적용한다. 현재 요청에 명시된 서식이 과거의 2단·필기 공간·미주 기본값보다 우선한다. 미주를 요청하지 않은 작업에 미주를 추가하지 않는다.

기본 계약은 B4, 1단, 자간 0%, 줄간격 180%, KoPubWorld돋움체 Medium 본문 11.5pt, 네이티브 수식 11pt, 연속 편집 가능한 본문이다. 역할별 제목·안내 크기는 10pt 이상으로 유지한다. 본문을 표 칸으로 분리하거나 이미지만으로 수식을 대체하지 않는다. 이미 검증된 수식 글꼴을 이름 통일만을 위해 치환하지 않는다.

## 원장과 중복

학년도·실제 고사·모의·공식 예시·회차·계열·원래 번호·고유 ID를 분리한다. 가이드 발행연도를 실제 출제연도로 자동 사용하지 않는다. 문제와 해설은 개수뿐 아니라 ID 순서까지 일치해야 한다.

중복은 개별 출처와 문제·조건·답·전체 해설·그림을 대조한 명시적 별칭 원장으로 처리한다. 유사도 점수나 그림을 제외한 본문 해시만으로 삭제하지 않는다. 재수록의 별도 보강 해설은 보존한다. 다른 형·다른 실제 시험의 동일 문제는 출제 이력을 남긴다. 기존 개별 파일은 삭제하지 않는다.

## 네이티브 보존과 병합

공통 지시문·제시문·머리말과 문항 사이 영역을 문항 번호 정규식으로 버리지 않는다. 모든 본문 문단은 문항 영역 또는 보존할 공통 맥락에 정확히 한 번 연결한다. 경계가 불명확하면 검증된 문서 전체를 보존하여 병합한다.

문서별 숫자형 스타일 ID는 다른 의미를 가질 수 있다. HWPX XML을 정의·자산 참조 재매핑 없이 이어붙이지 않는다. 한글의 검증된 InsertFile 경로를 쓰고 병합 후 글자·문단·스타일·테두리·탭·BinData 참조를 검사한다. 전후의 순서별 텍스트, 수식 스크립트와 소유 ID, 그림 바이너리 해시를 양방향 비교한다. 개체 수만 같은 것은 PASS가 아니다.

## 원문 모순과 출처

변환 오기는 원문으로 복구한다. 원문 무효는 대학 근거를 연결하고, 수학적 모순은 반례·불가능성 논증과 원문을 보존한다. AI 수정 제안과 AI 신규 해설은 공식 정정·공식 답안과 구분한다. 원문 조건을 몰래 변경하지 않는다. 배점 충돌도 풀이 오류와 구분한다.

원문 대조·검산·시각 검사·COM 재열림은 별개 게이트이다. 오래된 경로는 동일 SHA-256의 이동본으로 재연결할 수 있지만 이를 새 원문 검수로 세지 않는다. 후속 대조가 초기 미확인 상태를 종결한 경우 해당 문서의 안내만 교정하고, 다른 문서의 출처 한계를 일괄 삭제하지 않는다.

## 실행과 출고

기존 원본과 제공본을 보존하고 새 폴더를 사용한다. 한글 COM은 한 번에 한 세션만 실행한다. 실측 부하와 사용자 세션을 확인한다. 보안 모듈 성공 확인 전에 파일에 접근하지 않는다. COM 프록시 수명 문제가 있으면 파일별 격리 워커를 사용한다. 시간 초과는 기록하고 새 COM 투입을 중단한다. 출처 불명 프로세스나 사용자 문서를 자동 강제 종료하지 않는다.

대표 시험에 긴 수식·그림·공통 제시문·반복 번호·세트 경계를 포함한다. HWP/HWPX 각각 저장·닫기·재열림, 실제 KoPub 렌더, 쪽수·내용·그림·통권 쪽번호와 목차를 검사한다. 새 합본은 새 조판이므로 원본 문서의 시각 PASS를 그대로 복사하지 않는다. 300dpi 전 페이지 렌더 생성과 실제 검토 완료는 다른 값으로 기록한다.

최신순 정렬은 학년도 내림차순, 같은 학년도에서 실제→모의→공식 예시이다. 교사용 원문 진단·AI 수정안은 별도 부록으로 표시한다. 혼합 연도 문서를 통째로 유지한 경우 그 사실을 범위 원장에 명시하고, 세부 정렬이 완료됐다고 주장하지 않는다.

출고 목록은 단일 원장에서 생성한다. 대학별 자료와 공통 교사용 자료를 혼동하지 않는다. 파일 링크 집합·실제 파일 집합·해시가 일치해야 한다. 내용·수학·수식·그림·서식·COM·전 페이지 검수 중 미확인 게이트가 있으면 FINAL=false를 유지한다. 교재 원문·문항·결과물·개인 자료는 Git에 포함하지 않고 일반화된 코드·지침·합성 테스트만 반영한다.

일반 검증 API는 `app/hwp_collection_manifest.py`를 사용한다. 대응 순서, 문단 영역의 누락·중복, 참조 무결성, 증거 해시와 거짓 FINAL 승격 방지는 합성 회귀검사로 확인한다.

평문 그리스 문자 등 혼합 수학 기호 때문에 실제 PDF의 한글 본문이 대체 글꼴로 출력되는 경우, HWPX의 KoPub 이름만으로 통과시키지 않는다. 해당 기호의 뜻을 유지하는 네이티브 수식화는 원본 해시·문단·변환 전후 토큰·소유 문항·추가 수식 occurrence를 명시한 좁은 예외로 처리할 수 있다. `assert_declared_symbol_upgrade`로 다른 내용이 바뀌지 않았는지 검증하고 실제 한글 저장·재열림·렌더를 다시 검사한다. 원인과 무관한 Gulim·바탕 본문을 수식 글꼴 예외로 허용하지 않는다.

혼합 수식 문단에서 마지막 한두 글자만 다음 줄로 내려가는 현상은 KEEP_WORD 메타데이터만으로 해결됐다고 판단하지 않는다. 해당 문단의 실제 지면을 확인하고, 글자·수식을 축소하지 않는 최소 범위의 문단 폭 조정 등을 시험한다. 변경 문단과 이후 재조판 영역의 전후 렌더를 검증하고 예외의 ID·수치를 기록한다.

대표 시험에는 기존 native-only 변환 경로의 문서와 그리스 문자가 섞인 채점 안내도 포함한다. `app/hwp_collection_styles.py`의 `resolved_body_style_signatures`로 실제 사용 글자·문단·테두리·탭 정의를 풀어 비교한다. 같은 숫자 ID라는 이유로 같은 서식이라고 판정하지 않는다. 병합 중 widowOrphan·keepWithNext·keepLines 등이 풀리면 해당 문단만 복구하고 내용·전체 조판을 다시 검사한다. 정적 검사 모듈은 pyhwpx/COM을 가져오거나 전역 COM 캐시를 초기화하지 않는다.
