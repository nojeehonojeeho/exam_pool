# 교사 기준 문서의 서식 보존과 수정 출고

## 적용 범위

편집 가능한 원본을 교사 기준 문서의 지면으로 재배치할 때 적용한다.
기준 문서의 내용과 과목별 로고는 새 교재로 복사하지 않는다.
구조 PASS와 전체 출고 PASS를 분리한다. 아래 검사는 후보 해시별로 기록한다.

## 자산 및 서식 참조

- 머리말/바탕쪽의 위치는 기준본에서, 과목 이미지 내용은 해당 원본에서 가져온다.
- 원본 이미지의 해시, crop 좌표, 파생 자산 해시, 패키지 자산 ID를 연결한다.
- 모든 구역 및 첫/홀/짝쪽과 미주 페이지의 실제 렌더를 확인한다.
- refList 전체 교체와 숫자 ID의 의미 동일성 가정을 금지한다.
- 외곽선 제거는 새 무테 borderFill을 만들고 pageBorderFill만 연결한다.
  같은 테두리 ID를 쓰는 문제 표·조건 상자와 native 가운데 선은 바꾸지 않는다.
- HWPX 글꼴 이름만 검사하지 말고 실제 출력의 KoPub 글꼴 사용을 확인한다.

## 배치와 의미 보존

- 일반 B4 지면의 좌단 1/우단 2문항과 기준 필기공간을 목표로 한다.
  문항 마지막 개체와 다음 문항 시작의 실제 거리 및 본문 폭을 측정한다.
- 긴 문항은 1~2문항 지면으로 예외 기록한다. 빈 엔터 개수는 공간 증거가 아니다.
- 회차 제목의 페이지 나눔과 다음 문제의 페이지 나눔을 중복시키지 않는다.
- 정답 번호 문단은 다음 풀이와 묶어 번호만 단말에 고립되지 않게 한다.
- 긴 수식은 의미를 확인한 줄 분리를 우선한다. 표시용 줄 분리도 변경 원장과
  원본 대비 수식 토큰 보존 검사를 남긴다. 자동 줄 분리 성공은 가독성 PASS가 아니다.
- 기존 축소 수식은 문항/미주/occurrence별 크기와 실제 렌더를 다시 확인한다.

## 출고 게이트

1. 대표 지면: 짧고 긴 선지, 표/그림, 오른쪽 두 문제, 단원/회차 경계,
   마지막 문제/첫 미주, 긴 풀이 수식.
2. 원본 문항·정답·전체 풀이·수식·표·그림과 대응 출력의 내용 불변 검사.
3. 모든 문제 다음 새 물리 페이지에서 시작하는 native 미주 연결.
4. 전체 문항 범위 복사: 첫 anchor 문단만이 아니라 마지막 선택지/표/그림까지
   새 문서에 복사하고 미주 본문과 수식도 저장·재열림 후 대조.
5. HWP/HWPX 각각의 직렬 저장/재열림, 페이지 차이의 위치와 이유 확인.
6. B4 실제 크기 출력: PDF MediaBox와 축척을 검증한다. A4로 축소한 PDF나
   사후 MediaBox 확대는 B4 원출력 증거가 아니다.
7. 전 페이지 잘림·단 경계·고립 번호·빈 쪽·머리말·필기 공간 검사.

검사별 구현 위치, 입력/출력 해시, 검사 범위, 결과, 미해결 예외를 기록한다.
이전 후보의 PASS를 새 후보에 이월하려면 해당 내용 및 검사 입력이 불변임을 증명한다.
검증되지 않은 예외가 있으면 최종 출고로 승격하지 않는다.
