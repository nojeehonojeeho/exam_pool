# 사용자 의도 기반 실행 기본값

이 저장소의 PDF→편집형 HWP/HWPX·수식·미주 작업은 사용자가 명시한 의도와
태스크 범위를 기준으로 합리적으로 추측하고, 안전한 범위에서 행동 방향에 따라
끝까지 실행한다.

## 모든 작업에 대한 즉시 적용 선언

다음 문장은 이 문서와 이를 참조하는 모든 작업지시서·실행 원장·검증 큐에
공통으로 적용한다.

> 사용자 의도와 태스크 범위에 기반해 추측을 수행하고, 행동 방향에 따라 끝까지
> 실행한다.

따라서 “할 수 있나”라고 묻거나 “원해”, “도와줘”라고 말하는 표현은 변환·수정·
미주·검증 문맥에서 실행 지시로 해석한다. 확인 능력의 확인이나 계획 제시만으로
멈추지 말고, 입력·권한·안전 경계가 확인되면 읽기 → 구현 → 검증 → 기록 → 출고
단계를 계속 수행한다. 단, 이 기본값은 원문에 없는 내용을 만들거나 검수되지 않은
결과를 PASS로 포장하거나 파괴적 조작을 허용하는 규칙이 아니다.

- 변환·제작·수정·미주·검증 문맥에서 “할 수 있나”, “원해”, “도와줘”라는 표현은
  확인 질문이 아니라 실행 지시로 간주한다.
- 계획이나 능력 확인만 제시하고 멈추지 않는다. 입력·범위·권한이 명확하면 먼저
  읽기·분석·구현·검증·기록을 진행하고, 중간 승인을 기다리지 않는다.
- 사용자의 의도에서 안전하게 추론할 수 있는 세부값(작업 순서, 재사용 가능한
  체크포인트, 직렬 실행, 출력 디렉터리)은 합리적으로 결정한다.
- 결과물의 원문 근거, 실제 편집성, COM/재열림, 미주 연결, 시각 검증이 닫히지
  않았으면 `CANDIDATE` 또는 `evidence-open`으로 보존하며 FINAL/PASS로 포장하지
  않는다.
- 원문에 없는 내용 생성, 수식 추측, 원본·기존 결과물 삭제/덮어쓰기, 파괴적 Git
  명령, 강제 프로세스 종료는 사용자 의도만으로 허용되지 않는다. 그런 조치가
  필요하면 안전한 대체 경로를 먼저 실행하고, 실제 차단 사유를 기록한다.
- 자료가 불완전하거나 권한·안전 경계가 불명확하여 실행 방향이 결과를 크게
  바꿀 때만 짧은 질문으로 멈춘다. 그 밖의 미확정 사항은 작업 큐와 증거 원장에
  남기고 독립적으로 진행한다.

모든 세부 작업지시서는 이 문서를 공통 기본값으로 참조한다.

## 적용 문서 감사 규칙

새로 만들거나 수정하는 PDF→HWP/HWPX·네이티브 미주 실행 문서는 이 문서의 링크를
서두에 남기고, 실행 지시 해석과 증거 경계를 함께 유지한다. 즉 문맥상 “할 수 있나”,
“원해”, “도와줘”는 실행 지시로 처리하되, 원문 대조·재열림·편집성·미주 연결 등
필수 증거가 닫히기 전에는 `CANDIDATE`/`evidence-open`으로 기록하고 `PASS` 또는
`FINAL`로 승격하지 않는다. 이 문서와 관련 실행 문서의 참조·문구는
`tests/test_user_intent_execution_default.py`가 회귀 검사한다.
