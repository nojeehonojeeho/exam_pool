원본: [새 HWP 절대경로]
범위: [과목·유형편/실전편·회차·시작/끝]
서식 기준: [로컬 HWP/HWPX 경로]
모드: [template_only 또는 append_to_teacher]
출력: [통합 HWP/HWPX 2개 또는 전체 문제/해설/통합 6개]

AGENTS.md → docs/TEACHER_NATIVE_WORKFLOW.md와 연결된 v12/source fidelity/
COM 보안/미주 순서 정본을 먼저 읽고 실제 실행 경로에 적용해.
로컬 인계 패키지의 예외·실패·미확인 항목도 확인해.
과거 긴급 모델/병렬/재개 지시와 문항수/쪽수/crop/배치 예외는 자동 승계하지 마.

원본/기준본을 보존하고 새 폴더를 사용해. template_only는 형식만 가져오고,
append_to_teacher는 기존 내용·개체·미주를 유지한 사본에 추가해.
marker 수가 아닌 source-owned 문항/정답/풀이 개체와 경계·변형·반복 번호를
ID로 연결해. 다음 단원 교재정보 표가 이전 해설에 섞이지 않게 해.
문항·선지·정답·해설을 추측하지 마.

native_staged_reflow CLI는 검수된 native 후보의 조판 단계이지 임의 원시
HWP를 자동 인식하는 만능 변환기가 아니다. 새 원본용 경계/전송 어댑터가
없거나 append/다구역이면 필요한 어댑터부터 구현하고 대표 시험해.
확인된 native 개체는 OCR·페이지 이미지로 대체하지 마.

역할별 글자/문단/표/보기/수식/미주, B4 2단·가운데 선·외곽 테두리 없음,
약3문항과 실제 약60mm 필기 공간, 원본 과목 머리말 이미지, 실제 KoPub
렌더를 확인해. 같은 paraPr를 쓰는 제목과 본문은 의미로 구별해.
긴 식의 축소는 occurrence별 가독성 증거 없으면 통과시키지 마.
그림으로 시작하는 미주의 정답 제목이 이전 단 끝에 고립되는 문제는 알려진
미해결 사례다. keepWithNext/columnBreak 속성만 보고 해결로 판단하지 마.

모든 문제 다음 바로 다음 새 물리 페이지에 정답/전체 풀이 native 미주를
배치해. 대표 일반/긴 수식/표/그림/경계/마지막문제·첫미주 시험 후 전체로
진행해. COM은 공통 보안 helper/공유 lease/외부 deadline 아래 직렬 실행해.
HWP/HWPX 각각 저장·재열림·B4 실제 출력과 문항 전체 복사·이동을 확인해.
검증된 체크포인트는 해시가 유지되면 재사용하고 변경 영향만 재검사해.
원본→staging, staging→출력, 전 페이지 자동300dpi, 실제 본 페이지,
폰트/공간/해설 경계/복사 검사를 구분해. 부족한 증거를 과거 PASS로 채우지 마.
안전한 실행은 중간 승인 없이 이어가고, 반복 실패는 원인별로 기록해.
반복 오류는 코드·지시서·합성 테스트에 반영하고 교재/대화/개인자료는
Git에 넣지 마. 마지막에 실제 파일/범위/해시/검수범위/미해결 항목과
정확한 PASS/BLOCKED를 제공해. 완벽/누락0을 근거 없이 선언하지 마.
